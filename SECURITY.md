## Security

This is a hobby project that emulates an old DOS game, but if you find something that could hurt
people running it (for example the web build being able to touch things outside its own storage),
please report it privately through GitHub's
[security advisories](https://github.com/MorenoLand/Moreno.MuseumMadness/security/advisories/new)
rather than opening a public issue.

Only the latest version on the main branch is looked after.
